## 〇、先认错：上一版报告有两条结论是错的

写上一版时我用静态正则扫页面，漏看了「链接由脚本运行时赋值」这种情况，导致误判：

| 我上一版说的 | 实际情况 |
|---|---|
| ❌ B 项答案用了自创分类「概念混淆」，要你拍板 | ✅ **计划里本来就允许**。`Codex第二批任务prompt.md` 明确写了类型标签为「数值代入/量纲一致性/不等式关系/变化方向/**概念混淆（仅用于人工审核类）**」。实测 3 条概念混淆全部是 `judging=teacher`、来源 `caught_by=人工审核`，**零条混入自动判定** —— 完全合规，是我读漏了自己写的计划 |
| ❌ C 项"回知识点""跳锚点"没做 | ✅ **做了**。页面上 `<a href="index.html">` 只是占位，真正的锚点由脚本在切题时填入：`href = mainPage + '#' + 知识点id`、`href = mainPage + '#trap-' + 知识点id + '-' + 序号`。我静态扫 `href="#..."` 扫不到，误判成没做 |

**教训（已写进脚本注释）**：这个项目里凡是"动态生成"的东西，静态扫描会骗人。
以后验收必须**连可执行脚本一起看**，不能只扫 HTML 属性。

## 五、顺手修掉的一个真 bug
