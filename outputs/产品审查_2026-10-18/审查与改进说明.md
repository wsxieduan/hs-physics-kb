# 物理知识库产品审查与改进

审查日期：2026-10-18。状态：本地改进与完整机器验收完成，重复构建稳定；GitHub同步另有指纹核对回执。

## 判断

作为学生复习和教师查阅的离线知识点工具，现有内容规模和校验基础已经足够支持查阅。本轮的主要问题是查找路径和交付说明，已针对实际操作修复。它仍不能作为已经完成教师审核、实物实验和教学效果验证的成熟教学产品。

## 检查范围和方法

- 检查两个学段的全部46章、330个知识点、780条公式、742道诊断题的结构与自动检查结果。
- 核对速查页全部内嵌字段与已校验源的对应关系，不只核对总数。
- 对所有46章实际打开概览，核对每章所显示的知识点数量；测试7个主页面的手机、桌面布局。
- 实测自然输入、多关键词、领域与章节冲突、无结果恢复、排序、刷新与直链。
- 回归练习入口、阅读历史及记录导入导出。浏览器使用独立测试配置，没有读写用户真实学习记录。
- 抽查定义、适用条件和数学排版。自动检查与抽查不等于逐字完成全部内容的人工教学审定，没有虚构师生试用。

## 已处理的问题

| 视角 | 原问题 | 当前处理 |
|---|---|---|
| 学生 | 默认同时展开大量长卡片，难以先看某章内容 | 新增默认章节目录，选章后逐点展示定义及第一条公式，完整公式与条件可进入卡片查看 |
| 学生、教师 | “牛顿 第二定律”“平抛 速度”“欧姆 电阻”等输入要求连续匹配 | 空格分词并同时匹配，统一全半角；标题命中优先 |
| 学生 | 章节和领域可以形成矛盾筛选，导致空结果 | 自动解除冲突，显示当前范围，并提供一键清空搜索与筛选 |
| 学生 | 学生版搜索只作用于知识点，公式和符号索引未被真正筛选 | 补齐实际索引筛选；知识点索引包含折叠正文 |
| 学生 | 手机章节下拉框与领域按钮一起藏在横向滚动区 | 领域单独横向滚动，章节下拉框始终单独可见；导航、字号和留白重新整理 |
| 教师 | 缺少适于快速通览、打印的本章概要 | 从同一份已校验数据生成概览，支持打印，不另外推断考试权重 |
| 教师、维护者 | “内容已校验”容易被理解为完成教学审定 | 明确为自动校验通过、教学适用性仍待教师复核；保留原有待审状态 |
| 维护者 | 整合包中的当前验收可能仍是上次结果 | 构建后同步当前验收及机器报告，失败也照实同步 |
| 使用者 | 项目说明还是旧版本数字 | 更新为双学段330点780公式，区分本学段题量与全库742题 |
| 下载使用者 | 两个公开仓库各缺少另一学段页面，导航目标缺失 | 同步完整跨学段离线页面及构建所需公开数据，不改变两仓库定位 |

同步预览还发现，既有远端仓库对部分冻结脚本做过换行转换。代码逻辑相同，但文件指纹不同。同步采用当前已验收的原始字节，并为物理源码和成品增加保留换行的仓库规则；没有修改冻结引擎逻辑或重新封存基线。

全库742道题的教师审核状态仍为“待审”。机器可判题与教师点评题是判定方式分类，不表示其中一类已经经过教师审核。7份实验补全仍是设计示例，尚待实物验证；跨学段分级和部分教材分节仍待教师核对。

2026-10-06等历史收尾说明不再代表当前状态。例如其中仍将单摆频率写成精度争议，而当前源已经用未舍入周期换算，参考值为0.498233780392024 Hz，本轮未重复修改它。
